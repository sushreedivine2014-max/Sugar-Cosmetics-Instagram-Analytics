# Sugar-Cosmetics-Instagram-Analytics
Instagram performance analytics dashboard for Sugar Cosmetics analyzing KPIs, engagement rates, posting trends, content formats, and hashtag performance.
# Instagram Performance Analytics for Sugar Cosmetics

## Project Tasks

### Task 1: Overview KPIs – Brand's Instagram Summary
- Total number of posts.
- Total likes received.
- Total comments received.
- Total reach.
- Average engagement rate.

### Task 2: Monthly Posting Trend
- Analyze monthly posting frequency.
- Create a line chart showing the number of posts per month.
- Identify posting consistency over time.

### Task 3: Top 10 Posts by Likes
- Identify the top 10 posts receiving the most likes.
- Sort posts in descending order of likes.
- Include post captions or shortened versions for easy identification.

### Task 4: Top 10 Posts by Engagement Rate
- Identify the top 10 posts based on engagement rate.
- Analyze high-performing content beyond likes.
- Identify posts with strong engagement relative to reach.

### Task 5: Post Type Performance Comparison
- Compare different post types (Image, Video, Carousel).
- Analyze average likes, comments, and saves for each type.
- Identify the best-performing content format.

### Task 6: Day of Week Analysis
- Analyze average engagement across different weekdays.
- Extract day names from the post date.
- Identify the best days to publish content.

### Task 7: Engagement Funnel
- Visualize user interactions through the engagement funnel.
- Analyze the sequence: Impressions → Reach → Likes → Comments → Shares → Saves.
- Identify audience engagement drop-offs at each stage.

### Task 8: Hashtag Analysis
- Analyze the performance of different hashtags.
- Visualize average engagement rate or reach across hashtag groups.
- Identify effective hashtags for content strategy.

### Task 9: Final Dashboard – Instagram Insights Report
- Combine all previous analytical sheets into a single interactive dashboard.
- Add filters for Post Type, Month, and Hashtag (where available).
- Implement interactive filter actions.
- Add appropriate titles, legends, and formatting.

### Task 10: Strategic Recommendations
- Present key takeaways from the data analysis.
- Recommend posting strategies based on timing, frequency, and content types.
- Suggest ways to improve engagement and follower growth.
- Identify data gaps and provide solutions.
- Propose content and campaign ideas aligned with brand goals.
